04. Shared Equipment Checkout

PURPOSE
Help a training room lend shared equipment and record partial returns.

SCREEN
Equipment table, checkout form and session loan cards.

REQUIRED FEATURES
- List equipment with total and available quantities; search name and filter category.
- Create a checkout with borrower, item and quantity; list session loans.
- Return all or part of a session loan; update remaining loan quantity and availability.
- Show available units per item and count equipment types with zero availability.

RULES
- Borrower: 2–60 characters; checkout quantity: positive integer within availability.
- Return quantity: positive integer no greater than that session loan’s outstanding quantity.
- Seed unavailable units are prior loans and cannot be returned using this session’s loan form.
- A fully returned loan stays visible as Returned and cannot be returned again.

STARTER DATA
Read data.json: it is an array of 5 objects. Field names: id,name,category,total,available. IDs identify source records. For new records, choose numeric IDs greater than the largest existing ID and increment them. Any session contribution, loan, booking or shortlist collection starts empty; keep it separate from the source records.

ACCEPTANCE CHECKS (each starts from fresh seed data unless stated)
- Initially laptops: 5 available of 8.
- Check out 3 laptops: 2 available; return 1: 3 available and 2 outstanding.
- Return 3 against that outstanding 2: blocked with no quantity change.

OPTIONAL EXTENSION
Add an available-equipment-only filter.

Read START-HERE.txt and CSS-GUIDE.txt in the package root. Complete the required features before attempting the extension. All seed names, businesses, prices and records are fictional classroom examples.
